Power moves

crush(axis, amount)

Squash or stretch on one axis with volume preserved.

applyForce(dir, opts)

Inject velocity globally or in a falloff region.

setGravity(v)

Turn gravity off, on, or use a multiplier for heavier sag.

setFloating(bool)

Cut the floor loose and let the jelly bob freely.

sculpt(fn)

Reshape the rest pose vertex by vertex.

attach(obj, opts)

Glue any Object3D to the jelly surface — that's how the eyes work.

setEyes(config)

Button eyes by default, or supply your own factory.

impulse(strength)

One-shot wobble you can trigger from anywhere.

Quick start

import { Jelly } from './jelly.js';

const jelly = new Jelly({
  camera,
  domElement: renderer.domElement,  // pointer drag
  preset: 'petStar',
  floating: true,
  color: 0xe00072,
});

scene.add(jelly.mesh);

// every frame
jelly.update(delta);

jelly.crush('y', 0.45);                         // squash flat
jelly.applyForce([1, 0.4, 0], { strength: 2 }); // kick it
jelly.setGravity(2.5);                          // heavier sag
